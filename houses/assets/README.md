# 3D Model & Texture Assets

This directory contains external 3D models and PBR textures used for procedural building generation, interior furnishings, and architectural facade detailing in the European city apartment simulation.

## Directory Structure

```
assets/
└── models/
    ├── armchair/      # Arm Chair 01 (Poly Haven)
    ├── bed/           # Vintage Day Bed (Poly Haven)
    ├── bookshelf/     # Wooden Bookshelf Worn (Poly Haven)
    ├── cabinet/       # Modern Wooden Cabinet (Poly Haven)
    ├── chair/         # Wooden Chair 01 (Poly Haven)
    ├── desk/          # School Desk 01 (Poly Haven)
    ├── door/          # Large Castle Door (Poly Haven)
    ├── sofa/          # Glam Velvet Sofa (Khronos glTF Sample Assets)
    ├── table/         # Wooden Table 02 (Poly Haven)
    └── window/        # Rollershutter Window 01 (Poly Haven)
```
